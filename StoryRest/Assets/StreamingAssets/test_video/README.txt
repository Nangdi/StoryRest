테스트 영상 폴더 (CameraTest 씬 전용)
=====================================

Assets/1.Scene/CameraTest.unity 를 Play 하면 이 폴더의 영상을 마커와 상관없이 화면에 바로 띄웁니다.
프로젝터에 영상이 어떤 크기 · 화질로 나오는지 볼 때 씁니다. 전시 화면(StartScene)은 이 폴더를 읽지 않습니다.

* 넣는 것: mp4 · mov · m4v · wmv · avi · mkv · webm. 파일 이름은 자유이고 이름순으로 돕니다.
* 재생은 전시와 같은 AVPro 로, 소리 없이 반복합니다.
* Play 중에 파일을 넣거나 뺐으면 F5 로 다시 읽습니다.
* 영상 파일은 git 에 올라가지 않습니다(이 README 만 올라감).
* 빌드에도 그대로 실려 가니, 전시용으로 빌드할 때는 비워 두세요.

조작
  M          카메라 ↔ 영상 전환 (영상이 있으면 영상으로 시작)
  N / P      다음 · 이전 영상 (같은 장면 · 같은 크기 · 같은 자리로 바로 넘어감 = A/B 전환)
  C          나란히 비교 켜고 끄기. 폴더의 영상(최대 6개)을 칸으로 나눠 동시에 재생합니다.
             모든 칸이 1번 영상 기준으로 같은 화면 크기 · 같은 영역을 보여 주고, 휠 · 드래그가 모든 칸에 같이 걸립니다.
             해상도가 다른 영상도 같은 크기로 늘려 그리니 전시와 같은 조건으로 화질을 볼 수 있습니다.
             N / P 는 칸 순서를 한 칸씩 밉니다(1번 = 크기 기준).
  K          일시정지 · 재생 (보이는 영상 모두 같은 시각에 멈춤)
  , .        한 프레임 뒤 · 앞 (멈춘 상태에서)
  S          보이는 영상들의 재생 시각을 첫 영상에 다시 맞춤
  휠 · + -   표시 크기 (Shift 미세)
  Space      화면에 맞춤        Z  1:1 (영상 픽셀 = 화면 픽셀)
  드래그     영상 옮기기        G  격자(100px)      Tab  안내 숨기기

왼쪽 위 안내판에 파일 이름, 영상 해상도 · fps, 실제 재생 fps, 화면에 그려지는 크기가 나옵니다.
나란히 비교 중에는 칸마다 이름표(파일 이름 · 해상도 · fps · 표시 % · 재생 시각)가 붙습니다.
표시 % 는 화면 픽셀 / 그 영상 픽셀이라, 100% 를 넘으면 그 영상은 늘려 그려지고 있는 것입니다.
