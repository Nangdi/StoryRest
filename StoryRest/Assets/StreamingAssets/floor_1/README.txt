이 폴더에 마커별 영상을 넣습니다.
=====================================

폴더 이름 = ArUco 마커 번호입니다. 파일 이름은 자유입니다.

  floor_1/
    3/
      물의순환.mp4      <- 3번 마커에 이 영상이 뜹니다
    7/
      화산.mp4          <- 7번 마커
    12/
      별자리.mp4

규칙
----
* 폴더 하나에 영상 하나만 넣습니다. 여러 개면 이름순 첫 번째만 재생됩니다.
* 영상에 소리는 넣지 않습니다. 소리가 있어도 재생되지 않습니다.
* 권장 형식은 mp4 (H.264) 입니다.
* 폴더를 추가하면 그 마커가 자동으로 켜집니다. 설정 파일을 고칠 필요가 없습니다.
* 숫자가 아닌 이름의 폴더는 무시되므로, 보관용 폴더를 만들어 두어도 괜찮습니다.
* 쓸 수 있는 번호는 0~95 입니다. 96~99 는 화면 보정용으로 예약되어 있어
  폴더를 만들어도 영상이 뜨지 않습니다. 범위를 벗어난 폴더는 프로그램을 켤 때
  경고로 알려 줍니다. (미리 만들어 둔 폴더: 1~70)

파일을 바꾼 뒤에는
------------------
프로그램을 다시 시작하거나, 편집모드(F1)에서 F5 를 누르면 다시 읽습니다.

층 바꾸기
---------
StreamingAssets/Setting.json 의 "floor" 값을 1, 2, 3 중 하나로 바꾸면
그 층의 폴더(floor_1 / floor_2 / floor_3)를 사용합니다.
