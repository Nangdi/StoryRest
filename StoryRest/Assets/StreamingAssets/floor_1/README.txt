이 폴더에 마커별 콘텐츠를 넣습니다.
=====================================

폴더 이름 = ArUco 마커 번호입니다. 파일 이름은 자유입니다.
마커 폴더 안은 video 와 sprite 두 칸으로 나뉩니다.

  floor_1/
    3/
      video/
        물의순환.mp4    <- 3번 마커를 놓으면 그 위에 이 영상이 뜹니다
        설명.png        <- 영상과 이미지를 같이 넣으면 둘 다 뜹니다
      sprite/
        물방울.png      <- 벽면(키워드 월)에 떠다니는 그림
    7_화산/             <- 앞자리 숫자만 번호로 읽습니다 (= 7번). 제목을 붙여 두세요
      video/
        화산.mp4
      sprite/           <- 비워 두어도 됩니다
    12/
      video/            <- 비워 두면 12번 마커는 "콘텐츠가 없습니다" 안내만 뜹니다
      sprite/

video 폴더 — 마커 위에 투사되는 것
--------------------------------
* 영상(mp4 · mov · m4v · wmv · avi · mkv · webm)과 이미지(png · jpg)를 넣습니다.
* 폴더 안의 파일을 전부 띄웁니다. 이름순으로 그리며 나중 것이 위에 올라갑니다.
  순서가 중요하면 01_, 02_ 같은 접두사를 붙이세요.
* 영상에 소리는 넣지 않습니다. 소리가 있어도 재생되지 않습니다.
* 권장 형식은 mp4 (H.264) 입니다.
* 이미지는 투명 png 를 권장합니다. 검은 배경은 그대로 빛이 됩니다.

sprite 폴더 — 벽면(키워드 월)에 떠다니는 것
----------------------------------------
* 이미지(png · jpg)만 넣습니다. 영상은 무시합니다.
* 이 층의 sprite 폴더에 그림이 하나라도 있으면, 벽면에는 keywords.txt 의 낱말 대신
  그림들이 떠다닙니다.
* 폴더 전부를 띄우진 않습니다. 그림이 있는 폴더 중 프로그램을 켤 때 5~10개를 무작위로
  골라 그 폴더의 그림만 띄웁니다. 개수는 keywordwall.json 의 minSpriteFolders /
  maxSpriteFolders 로 바꿉니다 (둘 다 0 이면 전부).
* 그림이 하나도 없으면 예전처럼 keywords.txt 의 낱말이 떠다닙니다.
* 이미지 규격 (디자이너에게 이대로 요청)
  - PNG, 배경 투명(알파), 글자는 순백색(#FFFFFF). 색은 프로그램이 그라데이션으로 입힙니다
    (keywordwall.json 의 spriteGradients). 이미지에 색이 있으면 곱해져 탁해집니다.
  - 글자 가장자리의 부드러운 알파(안티에일리어싱)는 괜찮습니다. 그림자·외곽선·광택은 넣지 않습니다.
  - 글자에 딱 맞게 여백을 잘라 주세요(여백이 크면 실제보다 작게 뜨고 자리 계산이 어긋납니다).
  - 크기는 가로 700px 안팎, 2줄 글자 기준 높이 160px 안팎. 낱말끼리 글자 높이를 맞춰 주면 화면에서 크기가 고릅니다.
    (화면에서는 긴 변 360~760px 로 무작위 배율이 걸립니다)
  - 낱말마다 색을 따로 정해 주고 싶으면 색을 입힌 이미지를 주고 spriteGradients 를 비우면 됩니다.

공통
----
* 폴더를 추가하면 그 마커가 자동으로 켜집니다. 설정 파일을 고칠 필요가 없습니다.
* 숫자로 시작하지 않는 폴더는 무시되므로, 보관용 폴더(_보관 등)를 만들어 두어도 괜찮습니다.
* 쓸 수 있는 번호는 0~106 입니다. 107~110 은 화면 보정용으로 예약되어 있어
  폴더를 만들어도 영상이 뜨지 않습니다. 범위를 벗어난 폴더는 프로그램을 켤 때
  경고로 알려 줍니다. (미리 만들어 둔 폴더: 1~106)

파일을 바꾼 뒤에는
------------------
* video: 프로그램을 다시 시작하거나, 편집모드(F1)에서 F5 를 누르면 다시 읽습니다.
* sprite · keywords.txt: 프로그램을 다시 시작해야 반영됩니다.

층 바꾸기
---------
Setting.json 의 "floor" 값을 1, 2, 3 중 하나로 바꾸면
그 층의 폴더(floor_1 / floor_2 / floor_3)를 사용합니다.
